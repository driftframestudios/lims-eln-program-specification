# Repository boundary

This repository maintains vendor-evaluation requirements, data contracts,
specification-by-example scenarios, and Practitioner Probes.

GitHub branch protection, required reviews, secret scanning, and push protection
operate through repository settings and GitHub Rulesets. Product-selection,
scientific, Quality, Regulatory, privacy, security, and procurement decisions use
the organization’s established systems and processes. The repository records the
technical facts and questions those processes consume.

Changes receive ordinary pull-request review from maintainers familiar with the
affected domain. A change to a canonical primitive includes its API, event,
database, migration, export, and vendor-mapping implications.

The Machine Node supplies navigation and hydration. Its `runtime_effect` is
`none`.
