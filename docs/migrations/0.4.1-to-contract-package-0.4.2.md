## Interpretation and recovery

Exact raw strings can change serialized bytes and derived digests for inputs
whose whitespace earlier versions trimmed. Recompute derived artifacts from
retained source input through the receiving system's normal invalidation and
complete-publication route. A previously trimmed string has lost that source
information; the original input is the recovery authority.

The content validator scans the string in O(n) time with O(1) auxiliary space
and returns the original value. Other fields continue to use their existing
text constraints. Program release identity, sibling pins, credentials, tagged
publication, and operational acceptance retain their separate owners.
